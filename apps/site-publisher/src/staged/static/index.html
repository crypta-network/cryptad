Crypta content app

Site Publisher

Local site publishing

Queue a static site directory or a single file through Platform API content insert routes. Browser code sends only the operator-entered form fields and does not read arbitrary local files directly.

Submitted local paths and insert URIs are not written to browser storage or recent action history by this page.

Declared permissions

  • queue.read reads upload queue snapshots for publish progress.
  • queue.write creates insert queue requests for publish operations.
  • content.insert submits local file and directory content to the insert pipeline.
  • app.data.read and app.data.write read and save private durable drafts.
  • content.insert.app-document publishes saved literal text to a new CHK address after consent.

Beta readiness

Static site publishing

  • No source selected shows an empty state; invalid bundle, metadata, or queue errors use bounded copy.
  • Retry validation by re-submitting the form and retry queue inspection with Refresh queue.
  • Private plain-text drafts persist through restarts. Export and import use private recovery copies and an explicit guarded preview.
  • Support uses catalog metadata, operation categories, and redacted-summary-only diagnostics.

Private Sharesite plain-text drafts

Import only a converted private package from a consistent stopped Sharesite snapshot. Never select the original database here. The selected pastebin workflow preserves literal text; Textile, CSS, scheduling, deleted pages, and old USK writing are unsupported.

Approve the signed Site Publisher update and added permissions first. This workflow requires a daemon with guarded draft writes. Private copies contain user content and are not encrypted. Keep source snapshots and target backups separately in owner-only local storage.

Safe literal preview

      
      
      
Undo removes only an unchanged import. Later edits require private manual recovery.
        App bundle rollback is separate and keeps durable drafts, which may require the newer app to open.

      
      
      
Import, restore, undo, and save never queue publication. The old insert identity remains with
        its owner; this is not the next edition of the old USK. Disable old automatic publishing only
        after a separate operator cutover decision.
