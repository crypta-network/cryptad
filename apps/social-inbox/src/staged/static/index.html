Social Inbox Preview

Declared permissions

  • vault.identities.read lists public metadata for granted social signing identities.
  • vault.identities.create creates an app-owned preview identity without exporting private key material.
  • vault.identities.use requests bounded social-message signatures from AppVault.
  • content.fetch fetches bounded social outbox JSON selected by the user.
  • content.subscribe manages app-owned USK social source subscriptions.
  • content.insert.app-document queues generated social outbox snapshots.
  • queue.read reads upload queue summaries for outbox publication.
  • queue.write creates generated outbox publication inserts.
  • app.data.read restores bounded sources, summaries, drafts, and read state.
  • app.data.write saves bounded app-owned social inbox state.
  • trust.read reads Trust Graph Preview scores for message author annotations.

Migration spike status

This preview demonstrates a social/mail-like layer outside the daemon by combining AppVault identity, bounded signed message documents, content insert/fetch/subscriptions, app data, and Trust Graph Preview annotations.

  • It is not full WoT and is not compatible with old WebOfTrust plugin APIs.
  • It is not Freetalk, Sone, Freemail, and it is not encrypted mail or multi-recipient private messaging.
  • It does not add a daemon-core message store, moderation service, plugin ABI, or network protocol change.
