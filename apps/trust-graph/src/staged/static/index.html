Trust Graph Local RC

Declared permissions

  • trust.read reads local RC scope, anchors, statement lifecycle, and bounded scores.
  • trust.write imports bounded statements and manages local anchors and lifecycle policy.
  • content.fetch fetches statement documents through the bounded import helper.
  • content.subscribe manages trust statement content subscriptions.
  • content.insert.app-document stages generated statement documents.
  • queue.read previews local queue entries for trust publications.
  • queue.write creates queue entries for generated statement documents.
  • vault.identities.read lists visible identity metadata.
  • vault.identities.create creates app-owned statement identities.
  • vault.identities.use requests vault-authored trust statements.
  • app.data.read restores UI-local drafts, filters, and redacted import summaries.
  • app.data.write saves bounded UI-local RC state only.

Local RC scope

Local trust only. This app shows operator-curated local evidence; it is not global truth, not moderation, not blocking, not routing policy, not network crawling, and not legacy WoT/Freetalk/Sone/Freemail compatibility.

App id: trust-graph. Platform API contract: 22.

  • Draft form values, selected filters, and redacted import summaries persist through app data.
  • Anchors and imported statements persist through the platform trust graph backend.
  • Anchors and lifecycle records are local policy and are not published automatically.
  • The local Trust Score Service is read-only for other apps and requires operator-approved app-service grants.
  • Score evidence is bounded and must explain why a statement did or did not contribute.
  • Exchange uses content fetch, insert, and subscription APIs without crawling or protocol changes.
  • Fetched statement bodies are not displayed; pasted statement JSON is rendered only as text.
  • Statement authorship uses vault and trust exchange helpers without exposing private signing secrets.

Beta readiness

Local Trust Graph RC evidence

  • No anchors or statements show empty states; malformed, oversized, revoked, and deprecated statements use bounded errors.
  • Retry import, reload anchors/statements, refresh audit, or refresh queue from the controls on this page.
  • App-data export/import covers UI-local state. Schema 2 has dry-run migration ui-state-v1-v2.
  • Support uses local-only scope, operation categories, and redacted-summary-only diagnostics without raw signatures.
