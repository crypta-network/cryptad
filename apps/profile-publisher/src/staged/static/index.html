Profile Publisher

Declared permissions

  • queue.read reads upload queue progress for profile publishes.
  • queue.write creates insert queue requests for profile documents.
  • content.insert.app-document submits the node-readable profile document to the insert pipeline without local source-path access.
  • vault.identities.read reads granted public identity metadata.
  • vault.identities.create creates an app-owned profile signing identity.
  • vault.identities.use requests domain-separated signatures without exporting private material.
  • app.data.read restores the app-owned profile draft and publish summaries.
  • app.data.write saves bounded drafts and publish history summaries.

Beta readiness

Profile drafts and vault-scoped identity grants

  • No draft or no grant shows an empty state; vault grant and publish failures use bounded copy.
  • Retry identity metadata, request the grant again, or refresh upload queue progress.
  • App-data export/import covers profile drafts and summaries. Vault private identity material is not exported.
  • Support uses catalog metadata, grant state, operation categories, and redacted-summary-only diagnostics.
