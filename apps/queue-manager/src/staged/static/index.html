Declared permissions

  • queue.read reads local transfer queue snapshots.
  • queue.write queues downloads and updates queue requests.

Beta readiness

Queue operations for beta operators

  • No queue entries show a bounded empty state; queue fetch failures show a bounded error state.
  • Retry uses Refresh. Stuck transfers should use the Operator RC Recovery queue workflow.
  • App data is stateless; backup, export, import, and migrations are not applicable.
  • Support metadata comes from the first-party catalog policy and diagnostics are redacted-summary-only.
